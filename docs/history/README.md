# Project History

Records of how ATLAS was designed and built. They are kept for reference and
are not maintained: file paths and module names in them are the ones that
existed when each was written (before the move to the single `atlas_eng`
package, for example). For how ATLAS works today, start at the
[documentation index](../README.md).

| Folder | What it holds |
|---|---|
| [`blueprint/`](blueprint/) | The original vision, requirements and architecture blueprint |
| [`plans/`](plans/) | Plans for phases 13, 15 and 16 |
| [`reports/`](reports/) | Sprint reports from the Phase 16 production-readiness pass and release-candidate stabilisation |
| [`PROGRESS.md`](PROGRESS.md) | The phase-by-phase progress log |

The [changelog](../../CHANGELOG.md) is the maintained record of changes.
